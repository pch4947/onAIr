# 방 생성 API 연동 (#66)

이 브랜치는 화면 PR #67 (`feat/#66-station-create-form`)에 이어지는 변경이다.
PR #67 병합 후 main 기준으로 비교한다. 백엔드는 방송 생성 PR #69와
`feat/#66-persona-api-contract`의 오류 형식·30초 제한 보완을 함께 사용한다.

## 동작

- 로그인 토큰으로 보이스 조회 → 초안 3개 생성 → 수정본 검증 → 방송 생성.
- 화면의 camelCase 필드를 백엔드/공유 스키마의 snake_case로 변환한다.
- 첫 노래 지정은 백엔드에서 지원하지 않아 입력을 비활성화한다.
- 422의 `errors` 및 FastAPI `detail` 배열을 입력 오류로 표시한다.
- 생성 요청 재시도는 동일 본문에 같은 Idempotency-Key를 사용한다(모달이 열린 동안).
- 202 응답 후 2초마다 상태를 조회한다. `started`와 `hls_ready`가 모두 확인되면
  청취 화면 이동 버튼을 제공한다. 준비·거절·조회 실패를 구분한다.
- 보이스 조회와 초안 생성 실패는 다시 시도할 수 있다. 수정 검증 중 입력을 잠근다.

## 검증

프론트 폴더에서:

```powershell
npm.cmd run build
npm.cmd run lint
node --test scripts/station-create.test.mjs
```

수동 확인: Redis·백엔드·엔진(`--serve`)을 실행하고 로그인한 뒤 '방송 시작하기'에서
초안 선택과 방 만들기를 진행한다. 더미 엔진은 무음이며 실제 음성에는 TTS 설정이 필요하다.
실제 API 주소는 기존 `VITE_API_BASE_URL` 또는 Vite `/api` 프록시 설정을 따른다.

## 현재 범위

백엔드는 설정된 단일 방송만 지원한다. 기존 방송이 있으면 409이며 방송 종료·재생성은 후속 작업이다.
첫 노래 재생, 다중 방송, 모달을 닫거나 새로고침한 뒤 생성 작업 복원은 포함하지 않는다.
장르 10개는 팀의 잠정 선택지를 유지한다. 서버의 준비 상태와 사용자가 실제 들은 시점은 다르다.
